Station 1: Symbol Station

The containment console requires the symbol assigned to the isolation chamber.

Recovered symbol legend

  • Circle: observation chamber
  • Triangle: isolation chamber
  • Square: storage chamber

Console instruction: select the isolation chamber symbol.

Which symbol unlocks the containment console?

Station 2: Relay Station

The emergency power panel requires three relays to be activated in the correct order.

Maintenance note

  • Cooling must start before power.
  • Security must start after power.

Use both instructions to determine the relay order.

Which relay order restores emergency power?

Station 3: Archive Station

The archive terminal requires a three-digit code from the final laboratory record.

Final laboratory record

  • Observation chamber: 4 samples
  • Isolation chamber: 2 samples
  • Storage chamber: 7 samples

Terminal instruction: enter the sample counts in this order: isolation, storage, observation.

Which code opens the archive terminal?
